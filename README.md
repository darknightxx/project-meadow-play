- ใหม่ในรอบนี้: หน้าปกภาพใหม่ของเจ้าของ (ฮีโร่ 5 คนบนสะพานพญานาค), หน้าโหลดทุกหน้าใช้ภาพชุดของเจ้าของ 30 ภาพ (วาร์ปหรือเข้าเกมที่แมปเดิมซ้ำได้ภาพถัดไปวนกัน; แมปที่ไม่มีภาพของตัวเองใช้ภาพวางแผนเดินทาง), NPC ทั้ง 33 ตัวใช้โมเดลชุดใหม่ในสีชุดของตัวเอง (ไม่มีตัวเล็กหัวโตแบบเก่า ไม่ใช้ไฟล์ Indie-us; ครั้งแรกที่เข้าแมป NPC เป็นเงาตัวแทนสั้น ๆ ระหว่างโหลดโมเดล)
- ข้อจำกัดของ NPC รอบนี้: โมเดลเป็นฮีโร่วัยหนุ่มสาว NPC สูงวัยจึงดูเด็ก, หลายตัวหน้าและทรงผมซ้ำกัน, ยังไม่มีท่าทำงาน (ตีเหล็ก เสิร์ฟของ) จึงยืนเฉย ๆ; แมป cave_01 / goldcity_01 ยังใช้ภาพโหลดของตัวเองแบบเดิม
- จากรอบก่อน: แขนตอนวิ่งแกว่งตามสรีระจริง, นั่งพักมีวงแหวนแสง, อีโมตลูกโป่ง (Alt+1 ถึง Alt+9), ท่าดีใจตอนเลเวลอัป, หมวกชุดแรก, ท่าโจมตี/ร่าย/สกิลสร้างด้วยโค้ดของโครงการเอง, ตัวกันอาวุธทะลุตัว, ท่าวิ่งตามคลิปอ้างอิง, ท่ายืนฮีโร่ + เวทีหน้าสร้างตัวละคร, ผู้เล่นที่โหลดโมเดลใหม่ไม่ได้จะเป็นตัวแทนกลาง ไม่ย้อนไปโมเดลเก่า
- ชุดเทสเต็ม 32,530 ผ่าน / 0 ไม่ผ่าน บน `695bfca9`; ตรวจใน Chromium แบบ headless: หน้าปก → สร้างตัวละคร → หน้าโหลดลานฝึก → ลานฝึก → ข้ามบทสอน → หน้าโหลดเวียงธารหลิว → ในเมือง ไม่มีข้อผิดพลาดของสคริปต์ (เรนเดอร์ด้วยซอฟต์แวร์ จึงไม่ใช่ตัวเลขประสิทธิภาพ)
