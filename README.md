# Project Meadow — ตำนานทุ่งลมกระซิบ (เวอร์ชันเว็บ)

ไฟล์เกมเวอร์ชันเว็บที่บิลด์แล้ว (Godot 4.4.1) สำหรับ GitHub Pages

- เปิดลิงก์เฉย ๆ = เล่นแบบออฟไลน์คนเดียว (เซิร์ฟเวอร์จำลองในเบราว์เซอร์)
- โหมดออนไลน์ (ต่อเซิร์ฟเวอร์จริง) จะเพิ่มในรอบถัดไปผ่านพารามิเตอร์ `?server=wss://.../ws`

ซอร์สโค้ดไม่ได้อยู่ใน repo นี้
