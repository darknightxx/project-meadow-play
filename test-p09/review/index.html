หลักฐานส่งตรวจ: ตัวละครผู้เล่นชุด P09 (แชทโมเดลตัวละคร)

บิลด์ที่ส่งตรวจ: 2026-11-25 12:21 UTC · 2302cf71 (= main ของ project-meadow-clean) · หน้าเทสต์: /test-p09/

ภาพและคลิปทั้งหมดเรนเดอร์บนเครื่องคลาวด์ด้วยซอฟต์แวร์เรนเดอร์ ไม่ใช่การ์ดจอจริงหรือมือถือจริง: สี ประกาย และเฟรมเรตบนเครื่องจริงยังไม่ได้ยืนยัน ข้อมูลส่งตรวจฉบับเต็ม (ขอบเขต ไฟล์ ผลเทสต์ สิ่งที่ยังไม่ได้ทดสอบ) อยู่ในแถวของแชทนี้ใน BOARD.md

ตรวจใน Chrome ตามผลตรวจ 25 พ.ย. 2569 (BOARD.md): P09 หญิง / ชาย เดิน วิ่ง โจมตี เก็บของ · บิลด์ 2302cf71

หน้าเว็บจริงของบิลด์ 2026-11-25 12:21 UTC · 2302cf71 (ไฟล์ชุดเดียวกับ /test-p09/) เปิดใน Chromium 1280 x 720 เมาส์และคีย์บอร์ด โหมดออฟไลน์ของหน้าเว็บ สมัครบัญชี สร้างตัวละครจากหน้าสร้างตัวละคร แล้วเล่นในลานฝึกมือใหม่: กด W / D เพื่อวิ่ง, Tab โจมตีมอนสเตอร์ที่ใกล้ที่สุด, X เก็บของ
คลิปนี้ไม่ใช่ความเร็วจริง: เครื่องคลาวด์ไม่มีการ์ดจอ Chromium วาดด้วย CPU ได้จริงราว 1 FPS จึงให้เกมเดินเวลาคงที่ 1/20 วินาทีต่อเฟรมแล้วเก็บภาพทุกเฟรมจาก canvas ของเกม (เหมือนการอัดแบบ fixed-fps) ตัวเลข FPS บนจอและความลื่นจึงตัดสินไม่ได้จากคลิปนี้ สีและแสงก็เป็นของซอฟต์แวร์เรนเดอร์ ไม่ใช่การ์ดจอหรือมือถือจริง
คลิปของตัวละครชาย: ช่วงเดิน/วิ่งและโจมตีมาจากรอบแรก ช่วงเก็บของมาจากรอบที่สองของบิลด์เดียวกัน (รอบแรกกด X ก่อนมอนสเตอร์ล้ม จึงไม่มีของให้เก็บ)

สิ่งที่แชทโมเดลเห็นจากเฟรมที่เปิดดู (ทุกเฟรมที่ 8 ของทั้งสองตัว + เฟรมช่วงเก็บของ รวมราว 130 เฟรม): เท้าที่รับน้ำหนักอยู่ในเงาใต้ตัวทุกเฟรม ไม่เห็นช่องว่างระหว่างเท้ากับพื้น · ไม่เห็นขา แขน หรือผมทะลุชุดโนวิซ · ท่าเก็บของย่อตัวลงถึงพื้นแล้วลุก
ข้อจำกัดของหลักฐานนี้: กล้องของเกมมองลงค่อนข้างชัน จึงวัดความสูงของเท้าเป็นตัวเลขจากคลิปไม่ได้ (ตัวเลขอยู่ในเทสต์ tests_p09: เท้าแตะพื้นทุกท่า) · ตรวจเฉพาะชุดโนวิซของทั้งสองเพศ ไม่ใช่ทั้ง 24 ชุด · โนวิซโจมตีด้วยมือเปล่า จึงยังไม่เห็นการชักอาวุธ · ช่วง "เดิน" คือจังหวะออกตัวก่อนเป็นวิ่ง (เกมเลือกเดินหรือวิ่งตามความเร็ว) · ชุดโนวิซดูซีดในแสงของลานฝึกเมื่อวาดด้วยซอฟต์แวร์ ต้องดูบนเครื่องจริง · ยังไม่ได้ทดสอบบนมือถือจริงหรือการ์ดจอจริง

งานรอบใหม่ที่รอตรวจ (ยังไม่อยู่ใน main และยังไม่อยู่ในหน้าเทสต์): ท่านั่งและท่าขี่

สาขา claude/epic-bohr-69la5v · PR #20 SITRIDE รอบ 11 (Draft) ใน project-meadow-clean · เดิมสถานะ "นั่ง" และ "ขี่" ไม่มีท่าของชุด P09 จึงค้างเป็นท่าฟันดาบ · สัตว์ขี่ในภาพเป็นโมเดลชุดเก่า ไม่ได้แก้ในงานนี้ (เจ้าของจะให้ทำใหม่)

1. ท่ายืนตรง + สีชุดปัจจุบัน ทั้ง 24 ตัว (แสงเมืองของเกม)

2. ความคมและประกายตามริ้วผ้า: ก่อน / หลัง มุมเดียวกัน

ซ้าย = ก่อน (ค่าของบิลด์ ae4864c3) · ขวา = หลัง (บิลด์ปัจจุบัน) · ถ่ายก่อนแก้ท่ายืนตรง ท่ายืนในภาพจึงยังเป็นท่าเดิม

3. คลิปหมุนตัวละคร พร้อมกรอบใบหน้าและทรงผม (บิลด์ปัจจุบัน)

4. ท่าโจมตีปกติของทุกอาชีพ (จังหวะที่โจมตีโดน)

ภาพจากเครื่องมือดูท่า ไม่ใช่แสงของเกม ท่าสุดท้ายของแต่ละแถวคือท่าเสริม

5. ตัวละครในหน้าต่างสเตตัสและกระเป๋า

ซ้าย = ก่อน (ภาพ 320x360 ขยาย มีวงเวท) · ขวา = หลัง · ถ่ายที่บิลด์ ae4864c3
